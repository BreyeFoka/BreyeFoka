# Hi, I'm Breye Foka

Software engineer at SevenX and Computer Science student at the University of Kigali. I build products for Rwanda and the region (payments, marketplaces, school systems), plus the occasional ESP32 project. I solder, too.

**Portfolio:** [breyefoka.dev](https://breyefoka.dev) · **Case studies:** [breyefoka.dev/case-studies](https://breyefoka.dev/case-studies)

## What I've built

| Project | What it is |
| --- | --- |
| [OrivantaPay](https://breyefoka.dev/case-studies/orivantapay) | Mobile money payments infrastructure: checkout, payouts, signed webhooks, idempotent APIs. Rust and TypeScript. [orivantapay.com](https://orivantapay.com) |
| [Haulway](https://breyefoka.dev/case-studies/haulway) | Book a verified driver in Kigali; payment is held until delivery is confirmed with a code. Web and React Native. |
